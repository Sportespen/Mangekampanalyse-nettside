# mangekampanalyse.no

Statisk nettside for Mangekampanalyse Pro.

## Publisering

1. Kopier innholdet i denne mappen til det offentlige GitHub-repositoriet `Mangekampanalyse-nettside`.
2. Commit og push til `main` i GitHub Desktop.
3. Åpne **Settings → Pages** i GitHub.
4. Velg **Deploy from a branch**, branch `main`, mappe `/ (root)`.
5. Legg inn `mangekampanalyse.no` som Custom domain.

## Nedlastingsknapp

Nedlastingen er deaktivert inntil installasjonsfilen ligger på en offentlig adresse.
Sett adressen i konstanten `DOWNLOAD_URL` i `script.js` før offentlig lansering.
